## Math

Inline math such as $e^{i\pi} + 1 = 0$ renders with KaTeX, and so does display
math:

$$
\mathcal{L}(\theta) = -\frac{1}{N}\sum_{i=1}^{N} \log p_\theta(y_i \mid x_i)
$$

## Code

```python
def entropy(p):
    return -sum(x * math.log(x) for x in p if x > 0)
```
